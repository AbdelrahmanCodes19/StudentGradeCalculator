# Student Grade Calculator
## About the Project
A simple Java program that calculates student percentages and determines grades based on the entered score .
## Features
_ Accepts a student's grade .
_ Calculates the percentage . 
_ Validates grades between 0 and 100 .
_ Classifies grades into different categories .
_ Displays encouraging messages .
## Grade Classification
_ **90_100:** Excellent
_ **80_89:** Very Good
_ **70_79:** Good
_ **50_69:** Pass
_ **Bellow 50:** Fail
_ **Outside 0_100:** Invalid
Grade
